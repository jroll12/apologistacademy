OBS setup, no terminal

This page makes the scene file for OBS Studio. It works offline and sends nothing anywhere.

1. Where is the kit folder?

Unzip apologist-obs-kit.zip and put the unzipped folder somewhere you'll keep it, like Documents. Inside it are two folders, obs and slides. Copy the location of the obs folder:

  • Mac: in Finder, hold the Option key, right-click the obs folder, and choose Copy "obs" as Pathname.
  • Windows: in File Explorer, hold Shift, right-click the obs folder, and choose Copy as path.

2. Paste it here

3. Load it into OBS

  1. In OBS, open the menu Scene Collection, then Import. Click the … button to find the file Apologist Academy demo.json that just downloaded, then press Import.
  2. Open Scene Collection again and choose Apologist Academy demo.
  3. Open Settings, then Video. Set both resolutions to 1920x1080.

The five scenes appear in the Scenes box. If you move the folder later, make the file again.
